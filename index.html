Methods

Data

We analyzed the bfi data set distributed with the psych package. The original data set contains 2800 participants and 28 variables. The first 25 variables contain personality items measuring five broad personality dimensions; the remaining variables contain demographic information.

The five personality dimensions were Agreeableness, Conscientiousness, Extraversion, Neuroticism, and Openness. Items were scored using the scoring keys supplied with the psych package, including reverse-scoring where required.

Show code 
#| label: prepare-data

# Score the five BFI scales.
# scoreItems() also provides scale reliability estimates.
bfi_scoring <- psych::scoreItems(
  keys = bfi_keys,
  items = bfi,
  min = 1,
  max = 6,
  impute = "none"
)

# Convert the generated scale scores to a tibble and retain demographics.
bfi_analysis <- bfi_scoring$scores |>
  as_tibble() |>
  bind_cols(
    bfi |>
      select(gender, education, age)
  ) |>
  mutate(
    gender = factor(
      gender,
      levels = c(1, 2),
      labels = c("Male", "Female")
    )
  )

Scale scores represent the mean of the available items belonging to each personality dimension. Missing item responses were not imputed; scale scores were instead calculated from the available keyed items.

Analysis

We first summarized the distributions of the five personality scores and examined their internal consistency using coefficient alpha. We then fitted two linear regression models predicting Extraversion

The first model included age and gender as predictors. The second model additionally included Neuroticism and Conscientiousness. The nested models were compared in terms of their R² and information criteria.

Before interpreting the retained model, we visually evaluated its regression assumptions using diagnostic plots produced by the performance package. These diagnostics were used to examine residual normality, linearity and constant residual variance, influential observations, and multicollinearity.

Regression models

Before fitting the models, cases with missing values on the variables required by the larger model were removed so that both models were estimated using exactly the same observations.

Show code 
#| label: regression-data

model_data <- bfi_analysis |>
  select(
    Neuroticism,
    age,
    gender,
    Extraversion,
    Conscientiousness
  ) |>
  filter(age > 30) |> 
  drop_na()

The regression analyses therefore used 979 participants.

Show code 
#| label: fit-models

model_1 <- lm(
  Extraversion ~ age + gender,
  data = model_data
)

model_2 <- lm(
  Extraversion ~ age + gender + Neuroticism + Conscientiousness,
  data = model_data
)

Adding Neuroticism and Conscientiousness increased explained variance from R² = 0.019 to R² = 0.124. The larger model also had a lower AIC than the simpler model.

For this demonstration, we therefore retain Model 2 as the candidate final model.

Model diagnostics

Model comparison favored Model 2, so we next examined whether its assumptions appeared reasonable before interpreting its coefficients.

diagnostic_plots <- performance::check_model(

The diagnostic plots were examined for evidence of substantial violations of the assumptions underlying the linear regression model. In particular, we looked for strong departures from residual normality, systematic patterns in the residuals, non-constant residual variance, highly influential observations, and problematic collinearity among the predictors

Final model

#| label: final-model-table

final_model_table <- tidy(
  model_2,
  conf.int = TRUE,
  conf.level = .95
) |>
  mutate(
    term = recode(
      term,
      `(Intercept)` = "Intercept",
      age = "Age",
      genderFemale = "Gender: Female",
      Neuroticism = "Neuroticism",
      Conscientiousness = "Conscientiousness"
    ),
    # Format p-values for presentation
    p = case_when(
      p.value < .001 ~ "< .001",
      TRUE ~ sprintf("%.3f", p.value)
    )
  )

final_model_table |>
  select(
    term,
    estimate,
    std.error,
    statistic,
    conf.low,
    conf.high,
    p
